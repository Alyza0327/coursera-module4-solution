FILES INCLUDED
- index.html: webpage that loads the JavaScript files in the correct order.
- SpeakHello.js: prints "Hello Name".
- SpeakGoodBye.js: prints "Goodbye Name".

HOW TO RUN
1. Extract the ZIP file.
2. Open the module4-solution folder in Visual Studio Code.
3. Open index.html in a browser. If you have the VS Code Live Server extension, right-click index.html and choose "Open with Live Server".
4. In Chrome, press F12 and click the Console tab.
5. Confirm the output matches the expected output below.
